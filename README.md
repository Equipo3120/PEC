Bacteria Sulfoxidante (Quimiosíntesis del Azufre)
Este modelo 3D representa una bacteria procariota quimiosintética especializada en la oxidación de compuestos de azufre para la obtención de energía metabólica.
¿De qué trata el modelo?
El modelo muestra la estructura celular interna y la reacción química principal de la quimiosíntesis de azufre:
-Proceso Químico (H₂S → SO₄²⁻): Representa la oxidación del sulfuro de hidrógeno (H₂S) a ion sulfato (SO₄²⁻). Este proceso libera energía química que la bacteria utiliza para sintetizar materia orgánica a partir de dióxido de carbono sin necesidad de luz solar.
-Estructura Celular: Se aprecian las estructuras externas (flagelos y fimbrias/pili) e internas, como los gránulos metabólicos y las enzimas catalizadoras involucradas en la cadena de transporte de electrones.
